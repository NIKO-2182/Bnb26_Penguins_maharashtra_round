# Limits

- **Max IP Rotation**: 10,000 unique IPs per window.
- **Max Human Farm Capacity**: 5,000 concurrent connections.
- **Residential Proxies**: Only supported via provided simulation profiles.
- **PoW Difficulty**: Adjustable via `config.json`.
- **Max Requests/IP**: 100 per window (configurable).
